# Seasonal Agriculture Performance Analysis

A multi-dimensional empirical web platform analyzing agricultural performance, crop yields, resource efficiency, and financial margins across **Kharif**, **Rabi**, and **Zaid** cropping seasons across 4,000 farm records and 8 Indian states.

---

## 📋 Prerequisites

Before running the project, ensure you have the following installed on your machine:

1. **Node.js**: Version 18.0.0 or higher ([Download Node.js](https://nodejs.org/))
   - Verify installation in terminal:
     ```bash
     node -v
     ```
2. **npm** (bundled with Node.js):
   - Verify installation in terminal:
     ```bash
     npm -v
     ```
3. **Visual Studio Code (VS Code)** ([Download VS Code](https://code.visualstudio.com/))
4. **Google Chrome** (or any modern web browser)

---

## 🚀 How to Run the Project in VS Code & Open in Chrome

### Step 1: Open the Project in VS Code
1. Launch **Visual Studio Code**.
2. Go to **File** > **Open Folder...** (or press `Ctrl + K, Ctrl + O` on Windows/Linux or `Cmd + O` on macOS).
3. Select and open the root folder of this project (`Seasonal-Agriculture-Performance-Analysis`).

---

### Step 2: Open the Integrated Terminal in VS Code
1. In VS Code, go to the top menu: **Terminal** > **New Terminal**.
   - *Keyboard Shortcut:* `Ctrl + ` ` (backtick) on Windows/Linux or `Cmd + ` ` on macOS.
2. Confirm the terminal prompt is located in the project's root directory.
